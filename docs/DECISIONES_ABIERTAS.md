# Decisiones abiertas — no convertir propuestas de código en decisiones empresariales

**Confirmado para el producto público:** conservar Obsidian como entorno principal, Codex como agente de instalación y desarrollo, y una primera experiencia guiada basada en conocimiento real. Publicar el producto no aprueba una ontología definitiva, plugins comunitarios ni el contenido de ninguna empresa.

| ID | Decisión | Estado de diseño | Gate de aprobación |
|---|---|---|---|
| ADR-01 | Base visual de Obsidian | **Propuesto y construido:** Bases nativo | Verificar versión GUI y UX con dueño no técnico |
| ADR-02 | Plugin Obsidian Projects | **No instalado:** archivado/descontinuado; inspiración | Riesgo/mantenimiento/licencia y prueba en copia si se considera fork |
| ADR-03 | TaskNotes | Candidato opcional | Compatibilidad versiones, exportabilidad, plugin desactivado |
| ADR-04 | Modelo de 27 tipos | Candidato diferenciador + plantillas | Prueba de dos giros y tres casos contra clasificación errónea |
| ADR-05 | Clases D01–D07/X01–X07 | Metodología preservada vNext-1.0R | Piloto de desarrollo documental y gates G1–G7 |
| ADR-06 | Representación de relaciones | Contrato 0.9 y enlaces/tipos con fuente | Retrieval positivo/negativo y co-ocurrencia vs causalidad |
| ADR-07 | Autoridad por campo/asunto | Contrato 0.9, consulta exacta piloto | Acuerdo particular vs oferta general; dos fechas y conflicto |
| ADR-08 | Orquestación multiagente | Skills e instrucciones portables | Demostrar ejecución en al menos 2 harness con permisos reales |
| ADR-09 | Editor con aprobación | Solo crea propuestas, **no aplica** | Diff, backup, idempotencia, concurrencia, auditoría, reversión |
| ADR-10 | Derechos y roles multiusuario | No implementado | ACL externa o arquitectura de datos restringidos probada |
| ADR-11 | Sincronización/Drive/ERP/CRM | No conectados | Probar sistemas de registro por separado, scopes y revocación |
| ADR-12 | Estrategia de migración | Versiones declaradas, sin migrador | Dry-run + rollback desde bóveda anterior real sintética |
| ADR-13 | Política de licencia del producto | **MIT autorizada** para el repositorio público del producto general | No incluir bóvedas empresariales ni activos de terceros sin derechos |
| ADR-14 | Compatibilidad multiplataforma | CLI Python portable | Mac 2017, Mac actual, Linux, Windows en entorno limpio |
| ADR-15 | Interfaz de primera sesión | Inicio + Codex con skill, **propuesta** | Dueño sin experiencia completa C0–C6 con comprensión y utilidad |
